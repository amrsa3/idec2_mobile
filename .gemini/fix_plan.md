# خطة إصلاح شاملة للتطبيق

## المشاكل المطلوب حلها:

### 1. صفحة مستنداتي - لا تظهر المستندات ❌
**الملف**: `user_documents_viewer_screen.dart`
**المشكلة**: المستندات لا تظهر للمستخدم
**الحل المقترح**:
- فحص provider المستندات (userDocumentsProvider)
- التأكد من استدعاء API الصحيح
- فحص معالجة الأخطاء والحالات الفارغة
- إضافة logs تفصيلية للتتبع

### 2. صفحة الإعدادات - النص العربي يظهر كمربعات ⬜
**الملف**: `settings_screen.dart`
**المشكلة**: حقل اللغة وحقل مظهر التطبيق يظهران النص العربي كمربعات
**السبب المحتمل**: استخدام خط لا يدعم العربية أو مشكلة في encoding
**الحل المقترح**:
- استخدام خط يدعم العربية (مثل Cairo أو Tajawal)
- التأكد من استخدام TextDirection.rtl
- إزالة أي const من النصوص العربية

### 3. إضافة المصادقة البيومترية 🔐
**الملفات المطلوبة**:
- `login_screen.dart` - إضافة زر البصمة
- `settings_screen.dart` - إضافة خيار تفعيل/إلغاء
- `biometric_service.dart` - الخدمة موجودة بالفعل
**الحل**:
- تفعيل خدمة البصمة الموجودة
- إضافة UI للبصمة في صفحة تسجيل الدخول
- إضافة toggle في الإعدادات

### 4. تحسين القائمة الجانبية 👤
**الملف**: `app_drawer.dart`
**التحسينات المطلوبة**:
- إضافة صورة المستخدم
- إلغاء رقم الهاتف
- إضافة الاسم العربي (إذا كانت الواجهة عربية)
- إضافة الاسم الإنجليزي (إذا كانت الواجهة إنجليزية)

## خطة التنفيذ:

### المرحلة 3: تفعيل البصمة

### المرحلة 4: تحسين القائمة الجانبية
1. إضافة صورة المستخدم
2. تحديث عرض الاسم حسب اللغة
